# Bathri Sri weds Sri Nandhini · Wedding Reception e-invite

Live site: https://sabeshnav.github.io/bssn-reception/

- `index.html` is the whole site in one self-contained file (fonts, images and clips are inlined).
- `share.jpg` is the WhatsApp / social link preview.
- `source/` contains the code. Build it with `cd source && npm i && python3 build.py`, then copy `source/dist/index.html` to the root.
